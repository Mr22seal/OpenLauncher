# OpenLauncher

OpenLauncher is an independent, modular launcher for Minecraft: Java Edition.

## About

OpenLauncher is a Windows desktop application designed to provide a convenient way to install, manage, and launch Minecraft: Java Edition.

The project focuses on modularity, extensibility, and user customization.

## Features

- Minecraft: Java Edition installation and launching
- Microsoft account authentication
- Modular plugin architecture
- Customizable interface and themes
- Support for additional functionality through plugins

## Authentication

OpenLauncher uses Microsoft OAuth 2.0 Device Code Flow for account authentication.

Minecraft Services integration is intended to verify game ownership and retrieve the user's Minecraft profile.

The launcher does not provide game licenses or bypass Minecraft ownership verification.

## Platform

- Windows 10/11
- Minecraft: Java Edition

## Project status

OpenLauncher is currently under development.
